# 天際大廈 Sky Tower

仿 SimTower / Yoot Tower 嘅網頁起樓經營遊戲。純前端靜態網站，vanilla JS（ES modules）+ Canvas 2D，唔使 build step。

網址：https://fiveathree.github.io/simtower/（開咗 GitHub Pages 之後先有）

## 點樣玩

新遊戲只有資金同一幅空地，由大堂開始起一座摩天大廈：放租辦公室、賣住宅、開酒店，安排好電梯等住客唔使等太耐，將大廈由 1★ 經營到 **TOWER**。

- 所有人都由 **1F 大堂**出入，上層要有**電梯**或者**樓梯**先上得到。
- 每一層下面要有樓面承托；用「樓面」可以拖曳鋪空地板。
- 電梯同樓梯可以穿過住宅、辦公室等單位，單位都可以起喺電梯位上面；唯一唔准同另一條電梯或者樓梯重疊。電梯畫喺前面，撳嗰格會揀中電梯，拆卸都係先拆電梯。
- 高樓用**快速電梯**：喺 16F、31F、46F 起**空中大堂**（3★），快速電梯只停大堂層同空中大堂，再轉普通電梯。
- **貨梯**（2★）專俾酒店清潔同餐廳送貨用，住客同訪客唔會搭。
- 用「查看」點電梯可以加轎廂（最多 8 個，每個 $20,000），逐個設待命樓層同繁忙策略（早上優先向上、傍晚優先向下）。
- 辦公室同商店每季交租、住宅入住即賣出、快餐店靠午餐同訪客、酒店每晚收房租。
- 小人顏色：黑＝正常、粉紅＝等得有啲耐、紅＝好嬲。等太耐嘅租戶季尾會搬走，按「評價」睇邊度有問題。
- **人口＝租戶＋近 3 日平均每日訪客**。住客滿意，名氣就會慢慢升（滿分約 300 日），訪客越嚟越多。
- 酒店退房後要**清潔房**執房先租得出。住宅同酒店貼住辦公室或者快餐店會太嘈，扣評價。
- 地庫**停車場**要用**斜路**由 B1 連落去，車位夠就升住宅同酒店評價。**戲院**要揀片，舊片冇人睇。**地鐵站**要有電梯或樓梯連到 B4。
- 隨機事件：**火警**要保安到場先撲得熄，否則單位燒毀；**炸彈勒索**可以俾錢，或者等保安 4 個鐘內搵到；**VIP** 等電梯超過 5 分鐘，名氣下跌，兩季內唔可以升星；每年第四季**聖誕**訪客多五成。
- 用「查看」點單位可以揀租金高中低（高租金少人租、扣評價），睇租戶名同評價原因。按「財務」睇收支報表。
- 升級：2★ 人口 300；3★ 人口 1,000＋保安室；4★ 人口 5,000＋醫療中心＋回收中心＋酒店套房；5★ 人口 10,000；TOWER 5★＋天台教堂＋地鐵站。

| 操作 | 桌面 | 手機 |
|---|---|---|
| 起嘢 | 揀工具再撳；電梯由一層拖到另一層 | 同樣 |
| 拉長電梯 | 撳住頂格或者底格拖；面板有「向上／向下加一層」掣 | 同樣 |
| 移動畫面 | 拖曳、右鍵拖曳、`WASD`／方向鍵 | 拖曳 |
| 縮放 | 滾輪、`+`／`-` | 雙指 |
| 暫停 | 空白鍵 | 暫停掣 |
| 取消工具 | `Esc` | 揀「查看」 |

進度自動儲存喺瀏覽器 localStorage。

其他：第一次玩有 5 步新手教學（「說明」入面可以再睇）；「聲音」掣開關音效，預設靜音；「截圖」掣下載 PNG。

## 地點

開新遊戲時揀地點，每個地點嘅城市背景同天色都唔同。

| 地點 | 難度 | 起始資金 | 地盤 | 高度 | 特色 |
|---|---|---|---|---|---|
| 高雄 | 容易 | $5,000,000 | 120 格 | 40F | 人口目標低四成半（4★ 2,750、5★ 5,500） |
| 香港 | 中等 | $2,000,000 | 80 格 | 100F | 人口目標高 5%（4★ 5,250、5★ 10,500）；空中大堂每 15 層一個，去到 91F |
| 東京 | 困難 | $1,500,000 | 120 格 | 61F | 冇住宅；租金高兩成；地鐵客量多六成、商業容量多兩成；TOWER 要 12,000 人 |

有 3 格存檔，按「存檔」可以讀取、開新同刪除。舊版存檔會放入第 1 格，保留舊地盤大小（120 格、61 層）。

## 本機運行

因為用 ES modules，瀏覽器唔准由 `file://` 直接載入，要經 HTTP 開：

```bash
python -m http.server 8000
```

然後開 http://localhost:8000/。

## 部署到 GitHub Pages

1. 去 repo 嘅 **Settings → Pages**。
2. **Source** 揀 **Deploy from a branch**，Branch 揀 `main`，資料夾揀 `/ (root)`，撳 **Save**。
3. 等一兩分鐘，就會喺 https://fiveathree.github.io/simtower/ 見到。

Cloudflare Pages 都一樣：唔使 build command，輸出目錄係根目錄。

**轉 domain：** 改 `src/config.js` 嘅 `SITE_URL`，同時改 `index.html` 入面嘅 `canonical`、`og:url`、`og:image`、`twitter:image`。社交平台嘅爬蟲唔行 JS，只會讀 HTML 嗰幾行，所以兩邊都要改。

## 檔案結構

```
index.html      版面，載入 src/main.js
style.css       樣式
favicon.svg/png 網站圖示
og.png          1200×630 分享圖
src/
  main.js       啟動、主迴圈
  config.js     常數、設施資料表、星級條件、網站網址
  state.js      遊戲狀態、新遊戲、存檔／讀檔／migration
  build.js      放置規則、承托、拆卸、費用
  route.js      樓層圖、Dijkstra 路線、快取
  agents.js     小人行為
  elevator.js   電梯井、多轎廂派車、停站、繁忙策略
  schedule.js   每日日程、事件佇列、模擬一步
  economy.js    收入、支出、季度結算、升星
  events.js     火警、炸彈勒索、VIP、聖誕
  audio.js      即場合成音效，預設靜音
  render/       world（背景同樓面）、art（全部設施美術，程式繪畫加快取）、units（貼圖同狀態）、people（小人同轎廂）、overlay（預覽同浮動字）
  ui/           hud（頂欄）、tools（工具列）、panels（面板同對話框）、input（滑鼠觸控鍵盤）、tutorial（新手教學）
```

模擬部分（`src/*.js`）唔掂 DOM，要出訊息就經 `state.js` 嘅 `hooks`。

## 存檔

存檔放 localStorage 嘅 `skytower_save`，有 `version` 欄位。加新版本時喺 `state.js` 嘅 `MIGRATIONS` 加一步。目前係 v6，每格 key 係 `skytower_save_1` 至 `_3`；原型嘅 v1 存檔（`skytower_v1`）同之後嘅舊版存檔都會自動升級，舊資料保留唔刪。
